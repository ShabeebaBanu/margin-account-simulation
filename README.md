# margin-account-simulation setup and run

### 1. Clone the repository
git clone <REPO_LINK>
cd margin-account-simulation

### 2. Check if Python is installed
python --version
### If Python is not installed, download it from https://www.python.org/downloads/

### 3. Check if Jupyter Notebook is installed
jupyter notebook
### If not installed, install it using:
pip install notebook

### 4. Install required packages
pip install pandas
### random module is built into Python, no need to install

### 5. Open and run the notebook
jupyter notebook
### Open 'margin_simulation.ipynb' 

### 6. Git workflow for team
git pull
### After working on your section:
git add margin_simulation.ipynb
git commit -m "Completed Section X – <Your Name>"
git push
